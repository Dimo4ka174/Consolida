## О проекте

**Consolida** — внутренний инструмент для отдела логистики и закупок.
Позволяет оформлять заказы на поставку, рассчитывать их стоимость с
учётом налогов и доставки, и объединять заказы в **пулы** — группы,
которые едут одним маршрутом и делят транспортные расходы.

Проект писался как pet-разработка: интересно было сделать полноценную
слоистую архитектуру на .NET, потрогать разные подходы к кэшированию,
фоновым задачам и real-time обновлениям, и получить работающий
инструмент, которым реально можно пользоваться.

## Что уже планируется

- Учёт заказов: создание, редактирование, статусы, история изменений.
- Расчёт стоимости с налогами и скидками, конвертация валют.
- Консолидация: объединение заказов в пулы, отслеживание статуса
  пула в реальном времени через SignalR.
- Справочники: города, компании, заказчики, производители,
  логистические компании, единицы измерения, налоги, коды ТН ВЭД.
- Импорт и экспорт Excel.
- Ролевая модель и права доступа.
- Фоновые задачи: проверка дедлайнов, очистка блокировок.

## Технологии

| Слой           | Стек                              |
| -------------- | --------------------------------- |
| Runtime        | .NET 10, ASP.NET Core MVC         |
| ORM            | EF Core + Npgsql                  |
| БД             | PostgreSQL 16                     |
| Кэш            | Redis (опционально) + in-memory   |
| Real-time      | SignalR                           |
| Фоновые задачи | Hangfire                          |
| Логи           | Serilog                           |
| Аутентификация | ASP.NET Core Identity             |
| UI             | Razor Views, Bootstrap 5, jQuery  |
| Развёртывание  | Docker, Docker Compose            |

## Структура решения

```
Consolida/
├── Consolida/        # веб-приложение: контроллеры, вьюхи, точка входа
├── Application/      # бизнес-логика: сервисы, UoW, DTO, фоновые задачи
└── DB/               # EF Core: сущности, миграции, Identity, права
```

Зависимости идут в одну сторону: `Consolida` → `Application` → `DB`.
